Obsidian Sync

About

Obsidian Sync is a personal application used to synchronize Obsidian notes between my devices using Google Drive.

Functionality

The application uses Google Drive API to create, read, update and delete files required for synchronizing my Obsidian vault.

Data Usage

Google Drive data is accessed solely for synchronizing personal notes and attachments between authorized devices.

This application is intended for personal use and is not offered as a public service.
